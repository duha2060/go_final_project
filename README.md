# Планировщик задач (TODO-лист)

Веб-сервер на Go для планировщика задач. Сервер раздаёт фронтенд из директории `web`
и реализует REST API для работы с задачами, которые хранятся в SQLite.

Возможности:

- добавление, просмотр, редактирование и удаление задач;
- повторяющиеся задачи — при отметке о выполнении дата переносится по правилу повторения,
  одноразовые задачи удаляются;
- поиск задач по тексту и по дате;
- вход по паролю.

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/nextdate?now=&date=&repeat=` | следующая дата по правилу повторения |
| POST | `/api/signin` | вход по паролю, возвращает JWT-токен |
| GET | `/api/tasks?search=` | список ближайших задач (до 50), поиск по тексту или дате `02.01.2006` |
| GET | `/api/task?id=` | получить задачу |
| POST | `/api/task` | добавить задачу |
| PUT | `/api/task` | изменить задачу |
| DELETE | `/api/task?id=` | удалить задачу |
| POST | `/api/task/done?id=` | отметить задачу выполненной |

## Выполненные задания со звёздочкой

- порт сервера задаётся переменной окружения `TODO_PORT`;
- путь к файлу базы данных задаётся переменной окружения `TODO_DBFILE`;
- правила повторения `w` (дни недели) и `m` (дни месяца, в том числе `-1` и `-2`, с необязательным списком месяцев);
- поиск задач по подстроке в заголовке и комментарии и по дате;
- аутентификация по паролю из `TODO_PASSWORD` с JWT-токеном в куке `token`;
- Dockerfile для сборки и запуска в контейнере.

## Запуск локально

Нужен Go 1.26 или новее.

```bash
go run .
```

После запуска откройте в браузере http://localhost:7540/.

Переменные окружения (все необязательные):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TODO_PORT` | `7540` | порт веб-сервера |
| `TODO_DBFILE` | `scheduler.db` | путь к файлу базы данных; если файла нет, он создаётся |
| `TODO_PASSWORD` | пусто | пароль для входа; если пусто, аутентификация отключена |

Пример запуска с паролем:

```bash
TODO_PASSWORD=12345 go run .
```

При заданном пароле фронтенд откроет страницу входа http://localhost:7540/login.html.

## Тесты

Тестам нужен запущенный сервер. Сначала запустите его в отдельном терминале (`go run .`), затем:

```bash
go test ./tests
```

Параметры в `tests/settings.go`:

```go
var Port = 7540              // порт сервера (или переменная окружения TODO_PORT)
var DBFile = "../scheduler.db" // путь к базе (или переменная окружения TODO_DBFILE)
var FullNextDate = true        // проверять правила w и m
var Search = true              // проверять поиск
var Token = ``                 // пусто, если TODO_PASSWORD не задан
```

Если сервер запущен с `TODO_PASSWORD`, в `Token` нужно указать токен. Его можно получить так:

```bash
curl -X POST localhost:7540/api/signin -d '{"password":"12345"}'
```

или скопировать значение куки `token` в браузере после входа.

Тесты удаляют задачи из базы, поэтому не запускайте их на базе с важными данными.

## Docker

Сборка образа:

```bash
docker build -t todo-scheduler .
```

Запуск контейнера с базой данных на хосте в директории `./data`:

```bash
mkdir -p data
docker run -d --name todo \
  -p 7540:7540 \
  -v "$(pwd)/data:/app/data" \
  -e TODO_PASSWORD=12345 \
  todo-scheduler
```

Файл базы будет создан на хосте как `./data/scheduler.db`. Планировщик доступен по адресу http://localhost:7540/.
Если пароль не нужен, уберите `-e TODO_PASSWORD=12345`.
